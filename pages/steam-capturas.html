Gestión de bibliotecas Steam ✦

Capturas — Steam Library Manager

Sistema para gestionar, filtrar y compartir bibliotecas de Steam con estados de juego y colecciones personalizadas.

GitHub Capturas Código

Vista general

Steam Library Manager es una aplicación para organizar bibliotecas de Steam con filtros inteligentes, estados de juego y una experiencia rápida de compartir colecciones. Pensada para jugadores que quieren ordenar sus títulos y mostrar bibliotecas limpias a amigos o comunidades.

Capturas

Biblioteca Steam

Interfaz limpia para ver juegos, estados, horas jugadas y etiquetas personalizadas.

Filtrado

Filtros activos por estado, categoría, fecha y colecciones compartidas.

Compartir

Creación de colecciones para compartir con enlaces de vista previa o exportación.

Detalles

Tecnologías usadas
  • React
  • TypeScript
  • Steam Web API
  • CSS moderno
Características clave
  • Gestión de biblioteca con filtros y estados
  • Creación y exportación de colecciones
  • Vista de juegos con información de horas jugadas
  • Integración con Steam para mostrar datos reales
