# 💻 Portafolio de NYXAND

Este portafolio está hecho con HTML, CSS y JS puro. No tiene frameworks ni librerías extra, así que es fácil de entender y modificar.

---

## 📁 Qué hay en la carpeta

```
portfolio/
├── index.html              ← Página principal
├── css/
│   ├── style.css           ← Estilos generales
│   └── pages.css           ← Estilos de páginas internas
├── js/
│   ├── main.js             ← Menú, cursor y animaciones
│   └── projects.js         ← Filtro de proyectos (solo si usas projects.html)
└── pages/
    ├── capturas.html       ← Capturas de VoidemAbiss
    ├── codigo.html         ← Código / preview de VoidemAbiss
    ├── steam-capturas.html ← Capturas de Steam Library Manager
    ├── steam-codigo.html   ← Código / preview de Steam Library Manager
    └── contact.html        ← Página extra de contacto (no usada en el flujo principal)
```

> Ahora el portafolio principal funciona desde `index.html` y las páginas de proyecto de VoidemAbiss y Steam.

---

## ✏️ Cómo cambiarlo rápido

### 1. Cambia tu nombre
Busca tu nombre en `index.html` y cámbialo por el tuyo. También actualiza la descripción y la info en el hero.

### 2. Cambia los proyectos
En `index.html`, actualiza:
- título del proyecto
- descripción
- etiquetas
- enlaces a `pages/capturas.html` y `pages/codigo.html`

Si sumas otro proyecto, puedes crear una página nueva con el mismo estilo.

### 3. Cambia el estilo
En `css/style.css` están todas las variables de colores y el estilo base. Si quieres otro fondo, cambia `--white`, `--black`, `--gray-light`.

### 4. Cambia los textos
El texto principal está en `index.html`. Busca los bloques:
- hero
- proyectos
- experiencia
- educación
- contacto

### 5. Quita lo que no uses
Si no quieres usar `contact.html`, puedes dejarla guardada y eliminar los links internos de las páginas de proyecto.

## 🚀 Cómo publicar

### GitHub Pages
1. Sube la carpeta a un repo
2. Activa Pages en Settings
3. Tu sitio queda en `https://tuusuario.github.io/portfolio`

### Netlify
1. Arrastra la carpeta a [netlify.com/drop](https://netlify.com/drop)
2. Publícalo al tiro

### Vercel
1. Importa el repo en Vercel
2. Deploy automático cada vez que hagas push
